Hello, my name is Martynas Leonavicius and this is my first Java project.


Overview: I made Chess in Java to apply my newly acquired Java skills and further expand my understanding of OOP.

Features:
-Draws the chessboard with pieces
-Enforces legal movement rules for each piece
-Supports turn-based gameplay and check detection

Limitations:
-The game cannot identify if a player is in a checkmate, only a check

Technologies:
-JDK17
-JavaFX for UI rendering
-IntelliJ IDE
-Custom game logic developed withF default Java and JavaFX libraries

Learning context: The game was developed using knowledge primarily gained from MOOC.fi Java Programming courses developed by the University of Helsinki.
Statement of Generative AI Use: AI was used once to resolve an internal logic issue after extensive independent debugging.
